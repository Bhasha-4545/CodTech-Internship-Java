##  Project Description
This project demonstrates a simple recommendation system implemented in Java.  
The system suggests products to users based on previously stored user ratings.

It uses a basic collaborative filtering approach where recommendations are generated by analyzing preferences of similar users.

---

##  Features
- Product recommendation based on user ratings
- Simple collaborative filtering logic
- User-based recommendation model
- Console-based interaction
- Easy to understand implementation

---

##  Technologies Used
- Java
- Java Collections Framework (HashMap, HashSet)
- Scanner for user input
- Basic recommendation algorithm
